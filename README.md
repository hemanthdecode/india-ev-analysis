# India EV Adoption Analysis 2014-2024

## Project Overview
Analysed 96,845 rows of real Indian government EV registration 
data across 34 states from 2014 to 2024 to understand India's 
electric vehicle adoption patterns.

## Tools Used
- Excel 365 — data cleaning and pivot table analysis
- SQL (SQLite + DBeaver) — deep dive queries
- Python (Pandas + Matplotlib) — data analysis and charts
- Power BI — interactive dashboard with slicers

## Key Findings
- India sold 3.59 million EVs from 2014 to 2024
- Uttar Pradesh leads with 732,074 EVs sold
- 2-Wheelers dominate at 50.31% of all EV sales
- EV sales EXPLODED in 2022 — grew by 693,225 units in one year
- November is the best month due to Diwali festive season
- COVID caused a dip in 2020 but recovery was massive in 2021
